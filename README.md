
# YGO Card Explorer

A small learning project for browsing Yu-Gi-Oh! cards. It uses Express to serve the site and the YGOPRODeck API to retrieve card information.

## Run locally

Requires Node.js and npm.

```bash
npm install
npm start
```

Then visit http://localhost:5000

## What I'm learning

JavaScript, working with APIs, and building a simple site with Express, HTML, and CSS. MongoDB, Axios requests.
